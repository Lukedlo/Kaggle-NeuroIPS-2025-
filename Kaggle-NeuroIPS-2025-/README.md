# Kaggle NeuroIPS-2025
This project focuses on developing short Python 3 programs to solve grid transformation tasks for the Kaggle NeurIPS 2025 competition. Each task provides example input and output grids that demonstrate a pattern. The goal is to identify that pattern and write a program that applies the same transformation to new inputs.

The competition includes 400 tasks from the ARC-AGI public training set. Solutions must produce the correct outputs while using as few characters as possible. This project explores pattern recognition, problem-solving, and code optimization to build compact, accurate solutions.
